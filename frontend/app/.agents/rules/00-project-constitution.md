# Project Constitution

- Target sprint adalah 70–80% aplikasi Favera fungsional dalam enam hari.
- Kontrak public dan internal API v0.1 adalah baseline final sprint.
- Flutter hanya memanggil Express public API.
- Prioritaskan privacy, safety, correctness, dan flow yang bekerja.
- Semua screen utama harus reachable dan tidak memiliki dead end.
- Mock dan remote harus memakai repository contract dan model yang sama.
- Jangan mengubah route/schema diam-diam.
- Jangan menyebut transaksi sebagai judi atau bukti kesalahan.
- Jangan memberi diagnosis atau prediksi perceraian.
- Berhenti setelah menyelesaikan work part aktif.
