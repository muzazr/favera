# UI and Design Rules

- Ikuti `docs/DESIGN_BRIEF.md`.
- Gunakan token, bukan literal style tersebar.
- Visual: gradient lembut, card rounded putih, primary hijau, accent oranye.
- Min tap target 44×44.
- Semua screen scroll/keyboard safe.
- Tampilkan loading, empty, success, dan error sesuai kebutuhan.
- Jangan gunakan warna sebagai satu-satunya status.
- Copy harus netral, jelas, dan tidak menghakimi.
- Bottom nav: Home, Keuangan, Mediasi, Profil.
- Jangan membuat tombol aktif yang tidak bekerja.
