3.5 INTERPRETASI OUTPUT
--------------------------------------------------------------------------------
  anomaly_score    : 0.0 - 1.0. Semakin tinggi = semakin tidak biasa.
  risk_band        : "normal" / "unusual" / "needs_confirmation"
  reason_codes     : Daftar kode alasan seperti:
                       - AMOUNT_ABOVE_PERSONAL_BASELINE
                       - NEW_RECIPIENT_HIGH_AMOUNT
                       - LARGE_BALANCE_IMPACT
                       - BALANCE_NEARLY_DEPLETED
                       - HIGH_TRANSACTION_VELOCITY
                       - UNUSUAL_TRANSACTION_TIME
                       - REPEATED_SAME_AMOUNT
                       - LIMITED_USER_HISTORY
  personal_baseline_status:
    "available"           : Histori >= 8 transaksi, skor personal aktif
    "insufficient_history": Histori < 8 transaksi, skor personal = null
    "not_applicable"      : Tidak berlaku
  global_model_score:
    null (saat ini)       : Feature builder V5 belum tersedia.
                            Personal + Rule tetap aktif dan fusion berjalan.
